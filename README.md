# 需求澄清与规划｜Planning Skill

通过持续交流，把尚未完整表达的想法逐步转化为清晰的需求、可比较的选择和可执行的方案。需要看见具体结果才能判断时，用结果反馈校准需求；对目标或意思的理解会影响方向时，用复述反馈校准理解。

Through ongoing conversation, turn ideas that are not yet fully expressed into clear requirements, comparable options, and executable plans. When a concrete result is needed in order to judge, calibrate requirements with result feedback; when understanding of the goal or meaning would affect the direction, calibrate understanding with restatement feedback.
